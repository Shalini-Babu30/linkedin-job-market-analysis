# LinkedIn Job Trend Analysis

## 📌 Project Overview

The job market is constantly changing, and understanding which roles, skills, locations, experience levels, and salary ranges are most common can help both job seekers and businesses make better decisions.

This project analyzes **123,849 LinkedIn job postings** to identify employment trends across job categories, Data & AI roles, locations, experience levels, skills, companies, remote work, and salary.

The analysis goes beyond basic job-count reporting by creating a focused **Data Analyst job-market analysis** to understand the skills, compensation, locations, experience levels, and work arrangements associated with Data Analyst opportunities.

The project was built using **Python, Pandas, NumPy, and Matplotlib**, with a focus on data cleaning, feature engineering, exploratory data analysis, rule-based text analysis, and business insight generation.

---

# 🎯 Business Problem

Job seekers often rely on assumptions about which skills are important, which locations have the most opportunities, and what employers pay.

This project aims to answer these questions using actual LinkedIn job-posting data:

- Which job categories have the highest posting volume?
- How strong is demand for Data Analyst, Data Engineer, Data Scientist, and AI/ML roles?
- Which skills appear most frequently in Data Analyst job descriptions?
- Which locations have the highest concentration of job postings?
- What experience levels are most commonly requested?
- Which companies have the highest number of Data Analyst postings?
- What salary ranges are visible in the dataset?
- How does Data Analyst compensation vary by experience?
- How common are explicitly remote Data Analyst positions?

---

# 📊 Dataset

**Source:** LinkedIn Job Postings dataset available through Kaggle.

The dataset contains approximately **123,849 job postings** and includes information related to:

- Job titles
- Company
- Location
- Job description
- Experience level
- Work location type
- Salary
- Compensation type
- Job category

The raw dataset is not included in this repository.
